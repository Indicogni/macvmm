# The reference, unmodified. script(1) runs the command on a pseudo-terminal, so macvmm sees a real terminal and enters raw mode; the bytes Ctrl-A (0x01) and x arrive on it 2 s after the start, as if typed. $G is the repository's target/guests/aarch64-unknown-none/release. The capture tool prints the escape byte as \x1b and a carriage return as \x0d.
# Regenerate with scripts/capture-cmd (course/STYLE.md appendix A); never edit by hand.

exit: 0
